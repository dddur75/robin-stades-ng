# CLV 2026-27 — papier

Traitement local des championnats présents dans les fichiers d'entrée, sans appel
fournisseur, connexion de base, mise ou modification du scheduler.

```sh
PYTHONPATH=src python -m robin.clv --date 2026-10-18 --output artifacts/clv \
  chemin/odds-snapshots.jsonl chemin/robin-real-data.json
```

Entrées : JSONL de `JsonlSnapshotStore` (`OddsSnapshot`) et JSON normalisé `rows`
de `recurring_real_data`/`real_data_result`. Fournir l'historique couvrant les horizons
et la clôture ; aucune récupération distante automatique. Les répétitions identiques
sont dédupliquées ; prix ou coups d'envoi contradictoires font échouer le calcul.
Les clés FR réutilisent `config/archive.yaml` : Betclic, Winamax, Unibet, PMU, Netbet.
Pinnacle sert de référence ; Matchbook n'est pas un bookmaker FR dans ce périmètre.

Chaque date de coup d'envoi UTC produit `DATE-clv.csv` et `DATE-summary.csv`.
`match` est l'identifiant canonique, `horizon` est en heures, CLV/IC sont des ratios.
Le snapshot le plus proche gagne, le plus ancien en cas d'égalité ; il peut suivre
l'horizon visé, jamais le coup d'envoi. Observations et ingestions doivent toutes
deux précéder strictement le coup d'envoi ; les matchs futurs ne sont pas évalués.
Fenêtres inclusives FR/Pinnacle : ±6 h à T−48/T−24, ±1 h 30 à T−2 ; hors fenêtre : prix vide,
`MISSING_HORIZON`, `late` vide si un point Pinnacle manque ; `gap_minutes` = relevé − cible.
`close_gap_minutes` = coup d'envoi − clôture Pinnacle, qui peut le précéder de ~2 h (collecte 2 h).
La clôture et le fair T−2 exigent un triplet Pinnacle complet au même instant.
Le mouvement T−48 est sélectionné par issue ; seuil absolu de prix ≥5 %, EV T−2 ≥2 %.
`late` ne peut être vrai qu'à T−2 ; vide si le signal n'est pas calculable.
Les books présents ont une ligne par issue/horizon ; les prix/CLV manquants restent
vides avec statut explicite et sont exclus du résumé. Aucun book absent n'est inventé.
Bandes selon le fair de clôture ; IC95 Student sur les CLV, vide pour `n=1`.
Ces IC descriptifs supposent des observations indépendantes et ne corrigent pas la
dépendance entre issues d'un match. Aucun résultat sur données réelles n'est revendiqué.
