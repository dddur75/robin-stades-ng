# Critical Gate Readiness

Les gates sont mesurés par ligue. TEAM exige 99,5 % d’identités équipe.
PLAYER exige trois saisons, 90 % de fixtures, 99 % d’identités et de minutes
cohérentes. LINEUP exige trois saisons, 85 % de couverture, 99 % d’identités et
exactement onze titulaires sur une réponse complète.

MARKET 1X2 exige trois saisons, 90 % de couverture, 98 % de matching et zéro
ambiguïté utilisée. Totals exige 80 % mais ne bloque pas 1X2.

Un gate qui attend le backfill reste `BLOCKED_BY_COVERAGE`; ce n’est pas une
erreur opérationnelle.
