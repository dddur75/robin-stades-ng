# Cockpit Live V2

Le Cockpit V2 est une vue reconstruite depuis les preuves versionnées. Il expose :

- Command Center et funnel fixtures → règlements ;
- Coverage Explorer avec neuf fenêtres et états distincts ;
- Odds Explorer avec snapshots, dispersion et mouvements réels ;
- Match Center avec identités, disponibilité et explication ;
- Shadow Performance séparant legacy, OOS historique et live ;
- Pipeline & Qualité avec runs, stockage, SLO et incidents ;
- Coûts & Quotas avec prévision et réserve ;
- Data Explorer filtrable, triable et exportable en CSV.

Les badges `LIVE SOURCE`, `LEGACY SOURCE`, `OOS HISTORICAL`, `TEST EVIDENCE`,
`DEMO DATA` et `NO OUTPUT` sont contractuels. Le mode démo est désactivé par
défaut. Une absence reste vide ou `NO OUTPUT` ; aucune donnée n’est inventée.

Le statut global est `SHADOW_BURN_IN_ACTIVE` et le verrou
`PRODUCTION_LOCKED` reste visible sur toutes les pages.
