# Player & Model Cockpit

Le Deep Data Cockpit ajoute :

- Dataset Readiness : gates, saisons, couvertures et blocages ;
- Player Explorer : faits sourcés, force et incertitude ;
- Lineup Explorer : attendu versus confirmé simulé ;
- Feature Lab : couverture, statut et risque de fuite ;
- Model Lab : dataset, calibration, Log Loss, Brier et ECE ;
- Strategy Lab : seuils, volume, ROI, correction multiple et statut ;
- Backtest Explorer : résultats OOS sans mélange avec le live.

Le build GitHub publie un artefact mais conserve
`COCKPIT_PRIVATE_STALE` tant qu'aucun déploiement privé officiel automatisable
n'existe. Neon et les secrets restent côté serveur.
