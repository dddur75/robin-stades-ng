# Gouvernance OOS

| Période | Saisons | Usage |
|---|---|---|
| Discovery | 2020–2022 | hypothèses et fit |
| Validation | 2023 | sélection cross-fit |
| Exposed Historical OOS | 2024–2025 | évaluation gelée uniquement |
| Live Prospective | 2026–2027 | confirmation indépendante |

Toute sélection utilisant 2024–2027 est une violation. Une nouvelle hypothèse
issue d’un résultat exposé doit être enregistrée pour un futur corpus, jamais
réoptimisée rétrospectivement.
