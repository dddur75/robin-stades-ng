# Source-literal personal choices

The owner requests actual personal predictions observed before match. A published selection can be retained as a factual observation without establishing a normalized betting contract. NativeWin remains an unchanged, separate schema and bundle.

The additive schema `robin-opaque-tipster-facts-v1` contains an immutable source-result hash, lexical-parser hash, exact accepted source tip IDs, canonical fixtures and records whose discriminant is `market=source_native_opaque`. Its strict reader rebuilds the records from the independently pinned structured source observation and compares every value, including the original `sourceFields` dictionary. Values, scalar types, key presence and nulls are preserved. No source text is translated into a line, result, contract or UTC publication time.

Attribution requires the exact current author/profile route and unique tip ID. Fixture identity requires an unambiguous team-alias match to an already accepted canonical fixture; observedAt must precede its kickoff. The source event's civil date must match, but its timezone remains unknown. publishedAt, publishedCivilDate and sourceEventTimezone stay null.

Every record requires performanceEvaluationAllowed=false, settlementAllowed=false and marketInterpretationAllowed=false. The source field winew=Win is retained as a label, never interpreted as a winning result. Handicap values remain their original scalar representation; no Asian handicap splitting or totals interpretation occurs.

The public UI labels these as “Choix publié — marché source non interprété”. It never uses a predicted-score fallback for this type. Counts deduplicate sourceId/authorId/sourceTipId across literal and future normalized representations. Previous accepted facts remain visible if the new metadata, bundle or source evidence is absent or altered.

Initial scope: two already retained Bobby158 records, source IDs296416471 and296415336, event203186289, observed20November19:01:57Z before the independently proved19:45Z kickoff. Detailed records remain private. The change performs no HTTP, grants no recurrence/E2 and never activates a source by itself. C1 data and C4 scope reviews are required before integration.
