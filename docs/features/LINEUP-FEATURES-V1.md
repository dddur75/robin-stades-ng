# Lineup Features V1

## PRE_LINEUP

L'effectif actif est classé uniquement par titularisations et minutes
antérieures. Les onze premiers produisent force attendue, force du banc,
continuité et incertitude. La formation cible est absente.

## POST_LINEUP_SIMULATED

Le onze historique officiel peut être utilisé, mais le dataset porte les
marqueurs `HISTORICAL SIMULATED` et `POST_LINEUP_SIMULATED`. Il expose force
confirmée, banc, continuité, formation et différence avec l'attendu.

Les deux temporalités ne sont jamais fusionnées. Les tests adversariaux
interdisent toute composition cible dans `PRE_LINEUP`.
