# Pilote historique The Odds API

The Odds API n’est pas la source historique massive. Son usage est limité à la
Ligue des champions, aux trous de couverture et à un échantillon de contrôle.

Le dry-run enregistre `h2h`, `totals`, région `eu`, snapshots, coût estimé et
budget. Le plafond Jalon 9 est 500 crédits. Le run initial consomme zéro crédit;
aucun appel n’est automatique.
